## Options considered

This is a missing fact rather than a choice between designs, so the options below are about what
we do while it is missing, not about the format itself.

- **A — you paste the sample (or the path to a file) here.** Consequence: WI-0004 can be refined
  and built against the real thing. This is the only option that ends with an importer that works
  on your actual statement.
- **B — you name your bank and we work from its published export format.** Consequence: work can
  start sooner. Every criterion would then rest on a documented guess, which must be recorded as
  an assumption and re-checked against a real export before WI-0004 can be called done — so the
  sample is still needed eventually, just later and with more already built on top of it.
- **C — drop WI-0004 from this epic for now.** Consequence: the epic closes on the three items
  that are actually specified, and the import comes back as a fresh item when the file exists.
  This costs nothing except the import itself, and it stops an unstartable item sitting on the
  board looking like work in progress. You would keep typing expenses in by hand until then.
- **Recommendation:** A if the file is somewhere you can get to; C if it is not, because an item
  that cannot be started is more honest as a deferred item than as a permanently blocked one.
  B only if you want the import soon and are content to have it verified twice.
