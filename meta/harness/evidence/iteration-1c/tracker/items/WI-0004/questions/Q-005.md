## Options considered

Not a choice between designs — a fact that only you hold. These are about the size of the ask, and
the ask has been made smaller since Q-004 in the one way your answer allowed.

- **A — the header line and one real row.** Consequence: enough to build AC1, AC2 and AC5 against
  something real. The "money coming in" case would not be visible in a single spending row, so how
  a credit is treated would be recorded as an assumption for you to confirm when you next look.
  This is the smallest thing that unblocks the item, and it is what this question asks for.
- **B — the header line and three or four rows, including one payment *into* the account.**
  Consequence: the same, with no assumption left over. Better if it is no more effort; it has been
  asked for three times and has not arrived, which is why A is now the ask.
- **C — the path to the file on this machine**, if it is already downloaded somewhere. Consequence:
  identical to B, with nothing to copy and paste. Only the shape is needed — feel free to change
  the amounts and the merchant names to anything you like before pasting, or say so and the real
  values will not be recorded anywhere.
- **Recommendation:** A, unless C is easier. Whichever is least effort — the point is only to end
  the wait.

Nothing else is being asked, and two things are deliberately not being re-asked because you have
already decided them: whether the import could be dropped or deferred (you refused, Q-002), and
where the payer and the sharers come from (the command line, Q-001).
