## Context

configurable.**

you accepted them, with one thing on top: *"I don't want to pass `--rules` every single time, so
give the rule file a default spot it just picks up on its own"* — and *"don't bother with the
subfolder thing or undo, I don't need either of those"* [src: EP-001/Q-005]. That is the only work

was an acceptance of the nine items it listed and not of this one.

**This is that one thing, running.** The rule file now lives in your own config directory —
`~/.config/tidy/rules.ini` — your file, not one riding along in a folder somebody handed you, which
is the reason you gave for choosing it [src: WI-0004/Q-001]. The runs below are real, made just now
on a scratch folder; they point the config directory at `/tmp/tidy-so2/cfg` rather than at a real
home, which is why the paths look like that. On your machine that path is `~/.config/tidy/rules.ini`
and nothing else differs. `keepme/` is a subfolder that was already in the folder. Both output

With `.csv = data` in the rule file, and no flags at all:

That last one is a judgement we made on your behalf and you may disagree with it: a typo in a file

was already accepted once and nobody asked for this [src: tracker/items/WI-0004/item.md].
