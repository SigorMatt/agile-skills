## Context

**WI-0004, round 1, question 3 of 3 — the last one.** After this the item can be written down
properly and nothing else on it needs you.

A header cell can contain a line break too, and the header is the row the alignment marker most
obviously describes — the marker sits directly under it. Today it is centred like any other cell:

```
$ printf '| a<br>b | second column |\n|:---:|---:|\n| x | y |\n' | python3 -m mdtab
| a<br>b | second column |
|:------:|--------------:|
|   x    |             y |
```

(The header is the widest cell in that column, so nothing shows; give the column a wider body cell
and the header is centred within it.)

Your sentence was about cells and did not distinguish the header row, which is why this is being
asked rather than assumed either way.

## Question

**Does the rule apply to a header cell that contains a line break, the same as to a body cell?**

## Options considered

- **A — yes, the header is a cell like any other.** A header containing a line break sits left;
  one that does not goes on obeying the marker. Consequence: one rule, stated once, with no row
  exempt from it — the simplest thing to describe and the simplest to predict.
- **B — no, the header always obeys the marker.** Only body cells are affected. Consequence: the
  column heading stays where the marker puts it, which is where a reader's eye expects a heading;
  the price is a rule with an exception in it, and a header cell that renders on two lines while
  being padded as though it rendered on one.
- **Recommendation: A.** A rule with no exceptions is easier to live with than one that is right
  slightly more often, and if a header has a line break in it the same argument applies as for any
  other cell. Take B if you think of the header row as belonging to the marker rather than to the
  table's contents.

## Answer

[human] Yes, the header is a cell like any other — if it has a break in it, it sits plain at the
left too. I do not want a rule I have to remember an exception to, and a heading that reads on two
lines is no different from a body cell that does.
