because a criterion nobody can run is not a criterion.

Right now every one of them says `envel`. That word came from `project.name` in

the tool's own help text, so it is much cheaper to change now than later.

## Question

What do you want to type to run this tool?

## Options considered

- **A — `envel`.** Consequence: nothing changes; it is short, it is already the project name, and
  it is unambiguous on a shell path. It is also a word nobody chose on purpose.
- **B — `envelope`.** Consequence: it says what it is and is easy to remember; nine characters to
  type each time, which for a tool you use several times a day is a real cost.
- **C — something else you name.** Consequence: whatever you say replaces `envel` in every
  criterion on WI-0001, WI-0002 and WI-0003 before any of them is built.
- **Recommendation:** we lean to A, only because it is already written down everywhere and has no
  drawback we can see beyond its arbitrariness. That is a weak reason and we would rather you
  picked the word you would actually type.

## Answer

[human] `envel` is fine — keep it. It's short and I'll be typing it several times a day; I'm not
going to spend a round renaming things.
