## Context

This is one of six questions filed on `EP-001` in the first round, at intake. They are one
ask, not six: every one of them is about the idea you stated, and answering them together is
what lets the work start.

How we read your idea: you want a command-line tool, written in Python, with no services of any
kind, for envelope budgeting — you name envelopes, put income into them, record each spend
against the envelope it came out of, and see what is left in each. You also want a simple
summary of a month. Whatever you record must still be there the next time you run the tool.
That reading is what `EP-001`, `WI-0001`, `WI-0002` and `WI-0003` were written from; if it is
wrong anywhere, Q-001 is the place to say so.

This is question 2 of 6. The whole point of an envelope is that it can run out, so what the tool
does at that moment is a decision about what the tool is for, not a detail. It decides
`WI-0002` AC5, which is being held deliberately undecidable until you answer.

## Question

When I record a spend that is larger than the amount left in that envelope, what should the tool
do?

## Options considered

- **A — Refuse it.** The spend is not recorded, the tool says the envelope only has so much
  left, and nothing changes. Consequence: the tool never shows a negative envelope, and the
  figures always describe money you actually had. The cost is that it refuses to record
  something that really happened, so you would have to move money between envelopes first —
  which is itself not yet in scope (Q-005).
- **B — Allow it, and show the envelope as negative.** The spend is recorded and the envelope
  shows, say, −12.40. Consequence: what the tool holds always matches what you actually spent,
  and a negative number is the signal that you overspent that envelope. The cost is that you
  can drift a long way negative without the tool doing anything about it.
- **C — Allow it, but warn.** As B, and the tool prints a warning on that spend saying the
  envelope has gone negative. Consequence: B's accuracy with a nudge; the cost is more output
  to read, and a warning that stops being noticed once it appears often.
- **Recommendation:** ours would be C, because refusing to record real spending makes the tool
  disagree with your bank statement, and a bare negative is easy to miss. But this is squarely
  a question about how you want to be treated by your own budget, so pick the one you want
  rather than the one we like.

## Answer

[human] A — refuse it and tell me the envelope only has so much left. I don't want to see a negative envelope; if the money has to come from somewhere else then I want to move it there myself and record the spend after. See my answer to Q-005 — moving money between envelopes is something I want.
